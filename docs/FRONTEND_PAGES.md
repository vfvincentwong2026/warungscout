## 4. 页面路由规划

| 路由 | 页面 | 权限 | 说明 |
| :--- | :--- | :--- | :--- |
| `/` | 对外营销视图 | 公开 | 脱敏榜单 + 热力图 + CTA |
| `/login` | 登录页 | 公开 | 销售团队登录入口 |
| `/dashboard` | 销售作战室首页 | 需登录 | 今日待办 + 关键指标 |
| `/warungs` | Warung 列表 | 需登录 | 评分/等级/步骤列表 + 筛选排序 |
| `/warungs/:id` | Warung 详情 | 需登录 | 雷达图 + 步骤看板 + 建议 |
| `/tasks` | 待办看板 | 需登录 | 按优先级排序的任务清单 |
| `/feedback` | 反馈提交 | 需登录 | 完成动作 + 记录结果 |


## 5. 技术实现

### 5.1 前端技术栈

| 组件 | 选型 | 说明 |
| :--- | :--- | :--- |
| 框架 | React 19 + TypeScript | 现代 UI 框架 |
| 构建 | Vite | 极速构建 |
| UI 组件 | shadcn/ui | 美观、可定制 |
| 图表 | Recharts | 雷达图、柱状图 |
| 地图 | Leaflet / MapLibre | 印尼区域热力图 |
| 状态 | Zustand | 轻量状态管理 |
| 数据 | TanStack Query | 缓存 + 自动重试 |
| 认证 | JWT | 登录验证 |

### 5.2 关键组件清单

| 组件 | 路径 | 功能 |
| :--- | :--- | :--- |
| `RadarChart` | `components/charts/RadarChart.tsx` | 7维评分雷达图 |
| `ScoreBadge` | `components/ui/ScoreBadge.tsx` | 等级徽章（黄金/白银/潜力/普通） |
| `StepTimeline` | `components/warung/StepTimeline.tsx` | 步骤时间线看板 |
| `AdviceCard` | `components/warung/AdviceCard.tsx` | 下一步建议卡片 |
| `TaskList` | `components/tasks/TaskList.tsx` | 待办任务列表 |
| `FeedbackForm` | `components/feedback/FeedbackForm.tsx` | 反馈提交表单 |
| `WarungTable` | `components/warung/WarungTable.tsx` | Warung 列表表格 |
| `HeatMap` | `components/maps/HeatMap.tsx` | 印尼区域热力图 |

### 5.3 API 接口对接

| 前端操作 | API 端点 | 方法 |
| :--- | :--- | :--- |
| 获取 Warung 列表 | `/api/warungs` | GET |
| 获取 Warung 详情 | `/api/warungs/:id` | GET |
| 获取评分 | `/api/score/:id` | GET |
| 获取步骤建议 | `/api/advice/:id` | GET |
| 提交反馈 | `/api/feedback` | POST |
| 获取待办任务 | `/api/tasks` | GET |
| 获取统计概览 | `/api/stats` | GET |
| 导入数据 | `/api/import` | POST |


## 6. 用户交互流程

### 6.1 销售每日工作流
登录 → 进入 Dashboard

查看"今日待办" → 按优先级排序

点击高优先级任务 → 进入 Warung 详情页

查看"下一步建议" → 了解具体动作

执行动作（如发送 WA、电话联系、上门拜访）

点击"完成动作" → 弹出反馈表单

选择反馈类型、填写备注 → 提交

系统自动更新评分 + 推进步骤

返回 Dashboard → 处理下一个任务

text

### 6.2 对外访客转化路径
访问首页 → 看到数据总览 + 脱敏榜单

产生兴趣 → 点击"获取完整数据报告"

填写表单（姓名、公司、邮箱、需求）

提交 → 线索进入 CRM

销售团队跟进 → 转化为付费客户
